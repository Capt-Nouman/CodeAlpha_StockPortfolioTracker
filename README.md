## 🚀 About The Project

> A **console-based Python application** that allows users to build and track their stock portfolio. Users can input stock symbols and quantities, and the program instantly calculates the **total investment value** — with an option to save results as `.txt` or `.csv`.

No APIs. No internet required. Just pure Python. 🐍

---

## ✨ Features

| Feature | Description |
|---|---|
| 📊 **Live Portfolio Summary** | View your complete portfolio in a clean table format |
| 💰 **Investment Calculator** | Auto-calculates total investment per stock and overall |
| 🏦 **8 Major Stocks** | AAPL, TSLA, GOOGL, AMZN, MSFT, META, NFLX, NVDA |
| 💾 **Save as .TXT** | Export your portfolio summary as a text file |
| 📁 **Save as .CSV** | Export your portfolio as a CSV — opens in Excel |
| ✅ **Input Validation** | Handles wrong symbols, invalid quantities gracefully |
| 🔄 **Multiple Entries** | Add as many stocks as you want in one session |

---

## 🧠 Concepts Used

```
✅ Dictionary          →  Store stock names & prices as key-value pairs
✅ Input / Output      →  User interaction via terminal
✅ Basic Arithmetic    →  Price × Quantity = Investment
✅ File Handling       →  Write results to .txt and .csv files
✅ Functions           →  Modular, clean, reusable code
✅ Loops & Conditions  →  While loop, if-else for validation
```
